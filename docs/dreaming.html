Memex Dreaming

Memory consolidation system — three phases of autonomous knowledge maintenance

Three-Phase Pipeline

Light Sweep no LLM

  • xExact dedup — group by text, keep newest
  • xFragment purge — single-turn [user]/[assistant] entries
  • xNoise scan — isNoise() on all entries ("ok", "got it")
→

Deep Sweep no LLM

  • ↑Recall boost — recalled 5+ → importance ≥ 0.7
  • ↓Age decay — never recalled >30d → ≤ 0.3
  • ↓Session decay — imports >14d → 0.1, >30d → evict
  • ↓Ephemeral decay — "was committed/pushed" >30d → 0.1
  • xEviction — importance ≤ 0.05 deleted
→

Reflection needs LLM

  • ?Gather — top 50 memories (importance > 0.3)
  • →Synthesize — LLM produces 3 learnings
  • !Contradictions — SUPERSEDED markers demote old
  • +Store — learnings at category=learning, importance=0.85

Deep Sweep — Importance Scoring Rules

if recall_count ≥ 5 — frequently recalled, proven valuable
boost importance → max(current, 0.7)
if recall_count 1-4 — recalled at least once
boost importance → max(current, 0.5)
if recall_count = 0 + age > 90d — old, never useful
decay importance → min(current, 0.1)
if recall_count = 0 + age > 30d — aging, unproven
decay importance → min(current, 0.3)
if source = session-import + recall = 0 + imp ≤ 0.3 + age > 30d
evict importance → 0.05 (triggers deletion)
if source = session-import + recall = 0 + imp ≤ 0.3 + age > 14d
decay importance → min(current, 0.1)
if matches ephemeral pattern ("was committed/pushed/deleted") + age > 30d + imp < 0.5
decay importance → min(current, 0.1)

Reflection — LLM Knowledge Synthesis

1

Gather

Select top 50 memories with importance > 0.3, ordered by timestamp DESC

2

Prompt LLM

Send memories as [id] [category] text with system prompt asking for 3 themes + contradictions

3

Parse Output

Extract learnings (plain lines ≥20 chars) and SUPERSEDED markers (old_id|new_id|reason)

4

Store & Demote

Learnings → category: "learning" at 0.85 importance. Contradicted memories → demoted to 0.1

Idempotent: learnings are deduped via SHA-256 text hash. Running reflection twice produces the same result. Graceful skip: if <5 qualifying memories or no LLM configured, reflection returns immediately.

Intake Guards (Write-Time Prevention)

Text Hash Dedup

SHA-256 hash checked before embedding. Exact duplicates silently rejected. Zero cost — index lookup only.

Fragment Rejection

Entries starting with [user] or [assistant] blocked at store(). Raw dialogue is not distilled knowledge.

Noise Filter

isNoise() rejects filler ("ok", "got it", "thanks"). Prevents low-quality entries from ever entering the pool.
